# 标签体系（ChengOpenAI Life Notes）

共 30 个标签 = 10 个一级 + 20 个二级（<=30）。记录 frontmatter 的 tags 固定两枚：一级 + 二级。

- **日常**：散步 / 睡眠
- **饮食**：家常菜 / 探店
- **阅读**：重读
- **行走**：夜路 / 公园
- **城市**：街景 / 小店 / 声音
- **工作**：代码 / 文献 / 长任务
- **整理**：文件 / 旧物
- **朋友**：见面 / 远程 / 饭局
- **影音**：电影
- **灵感**：片段

## 字段规范

```yaml
---
title: 一句话标题（<= 20 字，不以标点结尾）
date: YYYY-MM-DD            # 必须 ISO 格式
tags: [一级, 二级]          # 必须来自上方体系，恰好两个
mood: 平静|松弛|专注|微倦|愉悦|怅然|好奇|踏实|明朗|慵懒
location: 城市（多数为上海）
cover:                      # 可空；如用图，放 public/images/ 下引用
---
```

正文：中文，80–180 字，具体、克制、有人味；避免鸡汤与口号；适合公开阅读。
文件名：`YYYY-MM-DD-拼音slug.md`，日期与 frontmatter 一致。
